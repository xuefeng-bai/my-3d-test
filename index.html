ADD A SCENE

新增一个 3D 项目

在仓库根目录执行脚手架命令，自动复制模板、替换占位符并登记到场景清单。

npm run new -- my-scene "我的场景" "一句话描述"

启动：npm start 或双击 start.cmd，然后访问 http://127.0.0.1:4173/。目录规范与字段说明见根目录 README.md。

  • 01每个场景一个 projects/<slug>/ 目录
  • 02入口固定为项目内的 index.html
  • 03共享 Three.js 用 ../../shared/ 相对引用
  • 04在 projects/registry.json 登记后自动出现在本页
