# 樱花街角 · 电车与便利店

白天晴暖的日式乡村车站街角微缩三维沙盘：单线电车与站台、临街 24 小时便利店、自动贩卖机、自行车、电线杆与持续落樱。

当前页面是 **VITRINE 外部参考案例**，不是本项目原创场景。

> 在线演示：[GitHub Pages](https://fanhuayishiy.github.io/ai-demo/sakura-station-corner/dist/)  
> 许可证：MIT（见 [LICENSE](LICENSE)）

## 场景

- 日式乡村车站街角，完整便利店内部（货架、冷藏柜、便当柜、关东煮、收银台等）。
- 单线电车与站台、自动贩卖机、自行车停放区、电线杆、三株持续落樱的樱花树。
- 底部天气条：晴 / 曇 / 雨 / 夕 / 夜；按键 `1`–`5` 直切，`W` 顺序循环。
- 可使用 `?style=toon` 切换低多边形平涂 / 三渲二风格。
- 首次打开需要装配大量程序化资产，启动画面会显示进度；在这台机器上可能需要数秒到十几秒。
