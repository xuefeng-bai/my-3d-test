# 雨夜便利店 · Yoru Mart

雨夜日式便利店街角的 3D 微缩模型，三渲二卡通渲染。当前页面是 **VITRINE 外部参考案例**，不是本项目原创场景。

> 原作者：Ray（[@Halorui-ai](https://github.com/Halorui-ai)）  
> 上游：[Halorui-ai/yoru-mart-diorama](https://github.com/Halorui-ai/yoru-mart-diorama)  
> 许可证：MIT（见 [LICENSE](LICENSE)）；字体使用 OFL，见 [fonts/OFL.txt](fonts/OFL.txt)。

## 场景

- 雨夜便利店街角：玻璃店面、发光招牌、店内货架与商品、海报、自动贩卖机、街道与雨。
- 完全离线：页面、字体和海报都已本地化，不请求 CDN 或远程资源。
- 无 UI 浮层；拖动旋转、滚轮/双指缩放、右键拖动平移。默认自动旋转，拖动后由用户接管。

## 本地打开

从 VITRINE 根目录执行 `npm start`，打开：

**http://127.0.0.1:4173/projects/references/yoru-mart-diorama/**
